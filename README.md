# qa-workflow-kit

A Claude Code plugin providing code-quality helpers for the Express API in `course-api/`.

## Status

Early scaffold (v0.1.0). Details to be filled in.

## Planned contents

- **agents/** — specialized subagents for reviewing and testing the Express API.
- **commands/** — slash commands for common QA tasks (linting, test runs, coverage checks).
- **skills/** — reusable skills encoding the project's code-quality conventions.
- **hooks/** — hooks that run quality checks automatically at key points in the workflow.
