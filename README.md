# Release Plugin

A multi-agent workflow plugin for managing releases. Orchestrates specialized agents to handle changelog generation, version bumping, and pre-release validation checks.

## Installation

```bash
/plugin install release@<marketplace>
```

## Usage

Run the release workflow:

```bash
/release
```

## What's included

- **Agents**: Specialized subagents for changelog analysis and version management
- **Commands**: Orchestrated workflow command to manage the full release process
- **Skills**: Release note generation and formatting
- **Hooks**: Pre-release validation checks
