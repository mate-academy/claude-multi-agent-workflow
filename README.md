
# API Quality Plugin

A multi-agent Claude Code plugin for Express API quality assurance.

## Features

- Read-only code review agent
- Automated test engineering agent
- Multi-agent quality workflow
- API testing skill
- Automatic post-edit hook

## Installation

```bash
claude plugin marketplace add YOUR_GITHUB_USERNAME/api-quality
claude plugin install api-quality@api-quality
```

## Usage

Run:

```text
/api-quality:quality-check
```

The workflow analyzes the API and generates a quality report.
