# Code Quality

When reviewing the API, focus on correctness, input validation, error handling, security, maintainability, and meaningful automated tests.

Prefer small, focused fixes. Every behavioral change should have an appropriate test when practical.

For reviews, report concrete findings with file names and severity. For fixes, explain what changed and verify the result with the relevant test command.
